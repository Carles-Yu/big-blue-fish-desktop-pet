# Gemini 额度查询

Windows 鱼鱼的角色右键菜单、托盘菜单在「额度查询」中增加 Gemini，位于 Codex 与 Cursor 之后。打开后自动读取一次；点击「刷新额度」手动重查。面板复用现有卡片布局，按模型组显示周限额与 5 小时限额的剩余百分比、重置时间与最近成功更新时间，时间使用本机时区；积分单独成卡，只显示剩余积分数，不把整数伪装成百分比。没有后台轮询或自动弹出的低额度提醒；剩余不超过 20% 时只在卡片内标记「余量较低」。Linux 没有此菜单。

## 数据与登录

只使用本机已登录的官方 Antigravity 命令行 `agy`，依次执行只读命令：

- `agy -p "/usage" --output-format json`
- `agy -p "/credits" --output-format json`

解析结构化结果中的 `command.data`，不根据文本 `response` 猜测字段，不调用非官方或内部接口，不读取凭据文件，不发起模型对话。`agy` 自己处理本机既有登录；鱼鱼不接收或保存登录令牌。额度不会进入聊天记录或记忆同步。界面和日志不展示命令原文、标准错误或服务端原始错误。

显示的是查询进程使用的本机 `agy` 登录账户。需要先在本机安装并登录 Antigravity 命令行。`/usage` 成功而 `/credits` 失败时，仍显示各模型组额度，并将积分标记为「未知」。缺少的数据展示「未知」，不是 0 或无限量；真实的 0% 剩余或 0 积分按 0 显示。刷新失败时保留上次成功结果并明确标记尚未刷新。

官方参考：[Usage](https://antigravity.google/docs/cli/commands/usage/)。该页说明的是交互式界面；本功能使用同一官方命令的非交互 JSON 输出。

## agy 路径

依次发现：环境变量 `BIGBLUEFISH_AGY_PATH` 显式路径、PATH 中的 `agy.exe`、当前用户目录下 `.gemini/bin/agy.exe`。显式路径必须是存在的绝对 `agy.exe`；无效时提示「环境变量 BIGBLUEFISH_AGY_PATH 不是有效的 agy.exe 绝对路径，请改成正确路径后再试。」，不静默换到其他程序。

每次查询启动隐藏的只读子进程，工作目录为当前用户目录，约 30 秒超时（两次命令共用这一时限）。完成后关闭标准输入并等待退出；超时或关闭面板时终止该查询进程及其子树。Windows Job 对象保障鱼鱼退出时回收。stderr 只排空，不保存或展示。
