## 两边各自在做什么

蓝色大肥鱼（本仓库，1.0.1）是 **C# / .NET 10** 桌宠：Windows 原生窗口，Linux 用 Avalonia。她用本机 Qwen3.5-4B（llama.cpp）或用户自备的云端接口，靠 OCR 读前台窗口，按生活节奏挑动作、开口说话。标准版另有 MCP，让外部 Agent **指挥**她（说话、播动作、截图、改设置）。发行物是安装包，另有编译期去掉 MCP 的无 MCP 版。没有 macOS。

dsh-pet-indesktop 是 **Python + PySide6** 桌宠：Windows、macOS（Apple 芯片）、Linux，另有 Android 工程。它从 DSH 运行时里拆出来独立运行，动画链更接近上游 `PC2005-cloud/dsh-pet`（待机 / 转向 / 移动 / 点击 / 拖动 / 随机），再叠了一层很厚的桌面工具：聊天窗、识屏、Agent **状态旁观**、歌词、语音、待办、灵动岛、多宠。AI 不内置本地模型，走用户自己的 OpenAI 兼容接口。打包是 PyInstaller onedir + Inno Setup，Chat / 无 Chat 两个变体。

两边的 106 段透明 WebM 都来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（MIT）。本仓库锁定在提交 `eb742677`，选择与触发是自己的权重表。对方在 v4.4.0 把短循环转成无损帧序列来省 CPU，长片段仍走视频。

## 对方的功能怎么分

核心能力不能关：透明置顶窗口、动画、角色素材、多宠身份、拖拽缩放、点击与碰撞、气泡、托盘、菜单、设置、更新。

可关模块在 `pet/features.py`，共 16 个。新安装默认只留核心；老用户升级默认全开。关掉的模块不进菜单、不跑后台，重启生效。

| 分组 | 模块 | 用户能感知的事 |
| --- | --- | --- |
| 生活 | 天气 | 中国天气网，Open-Meteo 兜底；菜单里换城市 |
| 生活 | 抽签 | 每日一签，可朗读、可每天提醒一次 |
| 生活 | 待办提醒 | 到点气泡或桌面通知，可提前、可语音 |
| 生活 | 节日提醒 | 节日、节气、生日文案；和动画权重不是同一套 |
| 声音 | 语音 | 报时、点击台词朗读、助手回复朗读。引擎：Edge（默认，免费在线）、Windows SAPI、MiMo、豆包。凭据进系统钥匙串 |
| 声音 | 音乐 | 跟着系统正在播的歌显示歌词、唱歌动作；菜单可打开网易云 / QQ 音乐 / 酷狗 / 汽水。歌词和「打开播放器」的路径无关 |
| 智能 | AI 对话 | 独立聊天窗（双栏或经典手机式）、流式、Markdown、会话分页、跨会话记忆、可选场景扮演、联网搜索。依赖用户自备 API |
| 智能 | 文件解读 | 把文件拖到身上，用对话模型讲内容。依赖 AI 对话 |
| 智能 | 看看屏幕 | 整屏或框选截图，交给视觉模型描述 / 翻译 / 回答。本地 OCR（RapidOCR + ONNX）不出本机；翻译和提问才联网 |
| 智能 | 主动识屏 | 默认关。在白名单窗口停留够久，截图问视觉模型，再冒一句。有冷却和每日上限 |
| 联动 | Agent 联动 | 默认关。只读本地事件：DSH 插件、Claude Code hooks、Cursor 转写、OpenCode 数据库，或自定义 JSONL。六态：thinking / working / attention / error / idle / sleeping，用来换动作和气泡。不回写、不替 Agent 操作电脑 |
| 联动 | 灵动岛 | 桌面胶囊：时间、CPU、内存、GPU、网速、游戏帧率（PresentMon，要用户加入 Performance Log Users）、DeepSeek 余额 |
| 系统 | 快捷启动 | 右键菜单开常用程序，最多约 20 项 |
| 系统 | 直播捕获 | 为 OBS 准备的单窗兼容模式，重启生效，OBS 仍可能黑屏 |
| 系统 | 多屏跨屏 | 默认关。允许拖到别的显示器；混合缩放时每块屏一张窗 |
| 系统 | 系统工具 | 回收内存；启动 / 停止本机 DeepSeek Harness |

另外还有一批不算「模块」、但和手感强相关的交互：拖动惯性与抛掷、弹弓、边缘探头、点击 Q 弹和音效、黄金回旋、多宠同进程、菜单布局可编排、全局快捷键（默认不绑）、省电（停预热）、隐藏时暂停解码、角色包热加载、Hermes 桥（`integrations/hermes-pet-bridge`）。

## 建议的吸纳顺序

按「用户能感到、又不改掉鱼鱼是谁」排序。每一项都在本仓库用 C# 重写，只把对方源码当行为说明。

1. **多屏与混合缩放。** 对方 v4.3.4 以后的结论可以直接当规格：缩放不一致时每块屏一张窗；静止落点不能停在两屏之间的空洞里。这是桌面宠物的正确性，不是彩蛋。
2. **拖动物理。** 松手惯性、抛掷、屏幕边反弹。点击、拖动中的现有动画继续用我们的表。
3. **语音。** 先做 Windows 系统语音，把报时和「把这句气泡念出来」接上。Edge / 豆包 / MiMo 涉及钥匙串和在线合成，单独再开。
4. **歌词。** 读系统正在播放的曲目，气泡或字幕跟歌词，并触发已有的唱歌类动作。播放器路径只负责「帮主人打开」，不要和取词绑在一起。
5. **待办提醒。** 本地条目，到点用现有气泡；安静时段沿用我们已有的暂停规则。
6. **Agent 旁观（可选，默认关）。** 只消费状态，不读转写正文。和 MCP 分开：MCP 仍是「Agent 指挥鱼鱼」。旁观开启前要写明它会读本机 Agent 的状态文件。
7. **主动发言的节流。** 把对方主动识屏里的停留、冷却、每日上限，用到我们已有的 OCR 发言上，而不是改成默认上传截图。

先不做：第二只宠物、灵动岛、游戏帧率、聊天工作台、场景扮演、Harness 启动器、OBS 捕获模式、Android、角色包市场。

## 合并时会撞上的约束

- **栈不能拼。** PySide6 窗口、Qt 对象生命周期、ffmpeg 子进程解码，都不能原样放进 .NET 进程。对方 v4.4 的帧序列是为了甩掉常驻 ffmpeg；我们若 CPU 成为问题，再单独评估解码，不要为了「对齐 v4.4」引入 WebP 帧缓存。
- **许可证。** 对方代码是 MIT，移植进 Apache-2.0 仓库时，被复制的文件要保留原版权声明，并在 `code/THIRD-PARTY.md` 记一笔。优先重写行为，少整文件搬。对方特意不用 GPL 的农历库（`lunardate` / `zhdate`），我们已有自己的农历节日计算，不要顺手抄那两个库。
- **素材不要双向覆盖。** 继续以 `PC2005-cloud/dsh-pet` 的锁定提交为动画来源。对方仓库里的帧序列、缩略图、角色包是派生产物。
- **隐私口径不要放宽。** 我们现在的默认是 OCR 文字进模型、截图不自动上传、记忆默认关、无 MCP 版连控制面都没有。对方的「看看屏幕」和主动识屏会把截图发给用户配置的视觉模型。若吸纳，必须默认关闭，并沿用 MCP 那种开启前说明。
- **Agent 方向不要混。** 对方是桌宠看 Agent；我们是 Agent 看桌宠并下命令。两套可以同时存在，不能合成一个开关。
