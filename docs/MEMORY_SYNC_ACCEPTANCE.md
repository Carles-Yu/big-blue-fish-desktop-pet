# 记忆同步试用交付与验证记录

日期：2026-10-26。范围：当前电脑、华为云 IPv6-only 服务器，以及本机两份独立客户端数据目录。未使用主人的正式记忆数据，也未覆盖已有鱼鱼安装。

## 本次完成

- 设备配对与档案接入分开。第一台设备明确创建档案，其他设备通过包含档案编号和密钥的加密传递包加入，避免各自连到不同档案。
- 恢复包导入保留原档案编号；更换服务器不会向新地址发送旧设备 Token。正式地址要求 HTTPS，本机 HTTP 只用于调试。
- 上传按最多 50 条分批，拉取按 200 条追完分页。解密并验证整页后，将数据和游标在同一事务中提交，错误页面不会被跳过。
- 离线连续编辑使用已确认的云端基础版本；请求期间的新修改不会误认为已上传。回执丢失后可幂等重试。
- 冲突保留双方文字，界面支持明确选择；未解决的冲突或拒绝不会显示成同步完成。
- 删除优先；改成仅本机时删除共享副本，同时用新的本机 ID 保留私人内容。接受云端重置清理共享记忆，保留仅本机内容。
- PostgreSQL 对同一档案的比较、写入和重置使用事务锁，避免两个并发请求同时通过旧版本检查。
- Windows 记忆页重排为「我的记忆 / 云端同步 / 备份与恢复」，日常编辑、配对和恢复分别展示；空状态、选择态、冲突态与窄窗口均已渲染验证。

## 如何在当前电脑试用

从仓库根目录运行：

```powershell
./tools/Start-MemoryPreview.ps1
```

该脚本启动 `.work/memory-preview-windows/BigBlueFish.exe`，记忆单独保存在 `.work/memory-preview-user/`；本地记忆默认开启，云同步、AI 自动调用、读屏、自动更新和 MCP 初始关闭。已有预览设置会保留，不反复覆盖。模型文件不随此预览携带；需要 AI 回复时再在设置中配置模型并主动启用。

在设置的「鱼鱼的记忆 → 我的记忆」里即可新增、修改、删除。要试用当前电脑的云同步：

1. 保持 Tailscale 在线，确认同步地址为 `https://hcss-ecs-1b1e.tailc95d8b.ts.net`。
2. 在终端运行 `./tools/Get-SyncPairingCode.ps1`，把生成的一次性码填到「云端同步 → 接入这台设备」。码 15 分钟有效，使用一次失效；脚本不读取或打印服务器管理密钥。
3. 点击「配对这台设备」，首次使用再点「创建新档案」。已有档案时应导入传递口令或恢复包，不能重复创建覆盖密钥。
4. 开启自动同步，点击「立即同步」，查看确认上传、待上传和冲突数量。
5. 在「备份与恢复」导出恢复包，单独保存。数据库备份没有客户端档案密钥，不能替代这份恢复包。

如果直接打开 exe，而不使用启动脚本，它会采用默认用户记忆目录，因此隔离试用请使用脚本。

## 备份运行状态

服务器部署了 `bigbluefish-backup.timer`：每天约 04:15–04:35（香港/北京时间同为 UTC+8）生成 PostgreSQL 一致性备份，AES-256-GCM 加密后保存到 `/var/backups/bigbluefish-sync`，保留 28 天。256 MiB 是当前明文 dump 的保护上限，超限会失败，需扩容备份方案；不会静默生成不完整备份。

备份密钥仅 root 可读，位于 `/etc/bigbluefish-sync/backup.key`；不放进备份文件、仓库或聊天。已在当前电脑保存一份校验通过的异机密文副本，及单独存放的恢复密钥，目录为当前 Windows 用户下的 `.codex/private-backups/bluefish/`，已移除继承 ACL，仅授权当前用户。

本机 Windows 任务 `BigBlueFishEncryptedBackupPull` 每天 04:50 拉取最新加密备份。错过时间后可在可运行时补跑；需要当前用户登录、Tailscale/SSH 和网络可用，不会唤醒电脑或要求登录密码。脚本只传密文和校验值，不日常传递密钥。手动执行可用：

```powershell
./tools/Pull-SyncBackup.ps1
```

本机离线时，服务器仍会做日备份，但新增备份需等本机再次在线拉取；这不是跨地域 OBS 容灾。无需为本次试用购买 OBS。

恢复演练命令与实现见 [原生部署说明](../server/deploy/native/README.md)。当前工具只提供认证验证和独立新库恢复演练，不提供一键覆盖正式库。若真要切换到旧备份，必须先停止同步并核对删除、代次、游标及设备授权，不能直接把旧库当作最新状态上线。
