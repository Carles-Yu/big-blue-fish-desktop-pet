# Provider icons

- `cursor.svg`: original `General Logos/Cube/SVG/CUBE_2D_LIGHT.svg` from Cursor's official [brand asset archive](https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/brand/cursor-brand-assets.zip), linked by [Cursor brand guidelines](https://cursor.com/brand). Original geometry and #26251e colour retained.
- `codex.png`: the light-background unplated 256px application mark from the installed official OpenAI.Codex Windows package (`assets/Square44x44Logo.targetsize-256_altform-lightunplated.png`, package 26.1021.3705.0). Official product reference: [Codex](https://openai.com/codex/). The public product page was checked; the local signed distribution provides the actual app icon.
- `gemini.svg` / `gemini.png`: official Gemini sparkle geometry from the mark used by [Gemini](https://gemini.google.com/), published at https://www.gstatic.com/lamda/images/gemini_sparkle_aurora_33f86dc0c0257da337c63.svg. The published asset embeds a raster image; this repo stores a compact SVG of the official path and the published gradient stops, plus a 256px PNG rendered from that SVG for WPF and the tray. Retrieved 2026-11-17.
